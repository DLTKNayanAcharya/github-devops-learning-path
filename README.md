# GitHub & DevOps Foundations Learning

This repository contains shared learning materials for Git, GitHub and DevOps foundations as part of the Unified Source Control Programme.

It supports preparation for the Costpoint rollout and provides a central place for course notes, practical exercises, videos, learning resources, questions and presentation materials.

## Learning objectives

By using this repository, learners should be able to:

* Understand the difference between Git, GitHub and DevOps.
* Explain the difference between Azure DevOps and GitHub.
* Use Git concepts such as clone, commit, branch, merge and remote.
* Understand the GitHub workflow from issue to pull request and merge.
* Understand code reviews, automated checks and GitHub Actions.
* Understand basic DevOps concepts, CI/CD and infrastructure as code.
* Identify the knowledge required before Costpoint go-live.

## Recommended learning path

1. Learning Git and GitHub
2. Learning GitHub
3. Practical GitHub Project Management and Collaboration
4. Learning GitHub Actions
5. GitHub Actions for CI/CD
6. DevOps Foundations
7. DevOps Foundations: Infrastructure as Code
8. DevOps Foundations: Your First Project

## GitHub Foundations playlist

The beginner GitHub Foundations playlist is:

1. Learning Git and GitHub
2. Learning GitHub
3. Practical GitHub Project Management and Collaboration

This sequence moves from core Git knowledge to using GitHub and then collaborating through issues, project boards and pull requests.

## Course review approach

Courses are reviewed based on:

* Relevance to the Costpoint rollout
* Difficulty for a beginner
* Clarity and accessibility
* Practical usefulness
* Missing topics or examples
* Must-know content versus optional later learning

The course-ratings table records relevance and difficulty scores. Feedback is used to create a final recommended learning path.

## Azure DevOps versus GitHub

The repository includes notes and video content explaining the difference between Azure DevOps and GitHub.

The comparison focuses on:

* Centralised versus distributed version control
* Check-in workflows versus branches and pull requests
* Code review and collaboration
* Automated checks and CI/CD
* How the change affects Costpoint consultants

## DevOps foundations

## GitHub certification

GitHub certification is recorded as a separate development consideration from the LinkedIn Learning foundation courses.

Its status should be confirmed as one of the following:

* Required
* Recommended
* Optional follow-on learning

Certification should not be described as mandatory until the programme requirement has been confirmed.

## Working guidelines

* Keep explanations clear for someone with no previous GitHub experience.
* Use descriptive file names.
* Keep course feedback specific and evidence-based.
* Record unanswered questions in the questions folder.
* Use branches and pull requests when making significant repository changes.
* Do not add confidential code, passwords, credentials or sensitive business information.
* Update the relevant notes when a course, video or recommendation changes.
